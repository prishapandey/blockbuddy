1 · Advanced Functionality — Blockchain Layer

Four blockchain features were added under a new On-Chain section that appears in the main page between the Campus Trust panel and the Project Flow section. A nav link labelled On-Chain (purple NEW badge) was added to the top navbar so the section is reachable without scrolling.

New file: src/lib/blockchain.ts

NEW src/lib/blockchain.ts

Pure TypeScript data layer. No external blockchain library required — uses a seeded LCG (linear-congruential generator) so all data is deterministic and reproducible across reloads.

  • generateTransactions(n) — produces n realistic on-chain transactions (hash, block number, from/to addresses, type, INR amount, gas, status, confirmation count). Sorted newest-first. Statuses: confirmed / pending / failed.
  • generateContractEvents(n) — returns events from three smart contracts (RentalEscrow, MarketplaceTrade, DepositVault) with severity levels (info / warning / success).
  • generateWalletStats(address) — per-address wallet analytics: totalSent, totalReceived, activeLocks, txCount, trustScore (0–100), activeSince.
  • generateActivityFeed(minutes) — per-minute volume and tx-count feed for the live activity chart.
  • TX_TYPE_LABELS / TX_STATUS_COLORS — label and colour maps for UI use.

New file: src/components/BlockchainSection.tsx

NEW src/components/BlockchainSection.tsx

Full React section component with four sub-tabs:

  • Transactions tab — filter pills (all / confirmed / pending / failed), expandable rows showing block number, confirmations, gas fee, from/to addresses. Live block counter increments every 8 s.
  • Smart Contracts tab — cards for RentalEscrow, MarketplaceTrade, DepositVault showing address, description, and event count. Event log below with colour-coded severity icons.
  • Wallet Analytics tab — INR totals, trust score progress bar, transaction-type breakdown with mini progress bars.
  • Live Activity tab — SVG bar chart of volume per minute (last 24 data points), live feed list, refreshes every 8 s via setInterval.

Also includes four KPI stat cards (Total Volume, Confirmed Txs, Pending, Gas Used) each with an SVG sparkline. No chart library dependency — sparkline is hand-drawn SVG polyline.

    2. Deposit sizing for micro-duration, micro-value rentals

    4. Reputation portability across annual student cohort turnover

4 · Vercel Deployment Fix

The production build passed locally but failed on Vercel. Four root causes were found and fixed.

Root CauseSymptomFix Applied
No vercel.json Vercel didn't know the framework; page refreshes returned 404 Created vercel.json with framework: "vite", outputDirectory: "dist", and SPA rewrite rule
__dirname in vite.config.ts Native config loader warning; breaks on some Vercel Node versions Replaced with import.meta.dirname ?? path.resolve()
__dirname in vitest.config.ts Same warning, potential breakage Same replacement
bun.lock committed alongside package-lock.json Vercel picked bun as package manager (not installed → install step fails) Added bun.lock to .gitignore
No Node version pin Vercel defaults to Node 18; some ESM packages behave differently Added .nvmrc pinned to 20
⚠️  Manual step required: Add VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY in your Vercel project's Settings → Environment Variables panel. Vercel never reads .env files from the repository.
